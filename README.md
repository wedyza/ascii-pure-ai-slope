Конвертирует любое видео в ASCII-арт анимацию с синхронизированным звуком. Загрузите видео, наблюдайте, как оно превращается в движущиеся текстовые символы, и воспроизводите его с оригинальным звуком — всё прямо в браузере.

## Возможности

- **Видео → ASCII конвертация** — Загружайте видео (до 5 минут) и конвертируйте их в ASCII-арт в реальном времени
- **Синхронизированный звук** — Оригинальный аудиодорожка сохраняется и воспроизводится вместе с ASCII-анимацией
- **Управление плеером** — Воспроизведение, пауза, перемотка и регулировка громкости
- **Тёмная/светлая темы** — Переключение между темами с мгновенным визуальным обновлением
- **Без состояния** — Данные не сохраняются; вся обработка происходит в памяти и автоматически очищается
- **Защита от скачивания** — Конвертированный контент невозможно скачать

## Технологический стек

| Уровень | Технологии |
|---------|-----------|
| Бэкенд | Python 3.11+, FastAPI, OpenCV |
| Фронтенд | Vanilla JavaScript, HTML5, CSS Custom Properties |

- Python 3.11+
- Node.js 18+
- [uv](https://github.com/astral-sh/uv) (менеджер пакетов Python)
- FFmpeg (опционально — нужен для извлечения аудио)

## API эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/api/v1/upload` | Загрузить видео для конвертации |
| `GET` | `/api/v1/conversion/{id}/status` | Проверить прогресс конвертации |
| `GET` | `/api/v1/conversion/{id}/frames` | Получить ASCII кадры для воспроизведения |
| `GET` | `/api/v1/conversion/{id}/audio` | Потоковое аудио |
| `DELETE` | `/api/v1/conversion/{id}` | Очистить данные конвертации |

## Конфигурация

Создайте файл `.env` в папке `server/`:

```env
ALLOWED_ORIGINS=http://localhost:3000
MAX_UPLOAD_SIZE=104857600    # 100MB
MAX_DURATION=300             # 5 минут
CONVERSION_TTL=300           # 5 минут
```

## Как это работает

1. **Загрузка** — Пользователь перетаскивает видеофайл (MP4, WebM, AVI, MOV) в область загрузки
2. **Конвертация** — Бэкенд извлекает кадры с помощью OpenCV, сопоставляет яркость пикселей с ASCII-символами (`@#S%?*+;:,.`) и опционально извлекает аудио с помощью FFmpeg
3. **Воспроизведение** — Фронтенд рендерит ASCII-кадры на 12 fps в элементе `<pre>`, одновременно воспроизводя аудиодорожку в элементе `<audio>`, синхронизируя их через выравнивание временных меток
4. **Очистка** — Все данные хранятся в памяти с TTL 5 минут; явная очистка происходит при выгрузке страницы
